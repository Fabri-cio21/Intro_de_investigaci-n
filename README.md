# Presentación: IA y diagnóstico cardiológico

## Estructura
Todos los archivos están en la raíz del repositorio para que coincidan con la organización actual de GitHub Pages.

- `index.html`: estructura de la presentación.
- `styles.css`: estilos visuales.
- `script.js`: navegación entre diapositivas.
- Archivos `.svg` y `.png`: recursos gráficos.

## Publicar en GitHub Pages
1. Sube todos los archivos de esta carpeta directamente a la raíz del repositorio.
2. En GitHub, entra a **Settings > Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
5. Abre la URL que GitHub Pages te indique.

No subas únicamente el ZIP: primero debes extraerlo y subir su contenido.
